# Unified Knowledge Directory

Phase 3.5 consolidation root. All durable knowledge lives under one of three
subdirectories:

- `incoming/` — candidate research and unprocessed intake (former `research/incoming`, `research/pending`).
- `materials/` — research materials and supporting artifacts (former `research/` remainder, corpus, reviews).
- `activity/` — learning activity, sessions, plans, progress, tasks (former `learning/`).

Code packages (`learning_engine/`, `wks/`, `orch/`) remain in place; only data moved.
Retired roots `learning/` and `research/` are preserved under `superseded/`.
