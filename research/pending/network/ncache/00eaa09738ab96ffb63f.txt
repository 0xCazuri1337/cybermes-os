 Adversaries may use Valid Accounts to interact with remote systems using Windows Remote Management (WinRM). The adversary may then perform actions as the logged-on user. WinRM is the name of both a Windows service and a protocol that allows a user to interact with a remote system (e.g., run an executable, modify the Registry, modify services). [1] It may be called with the winrm command or by any number of programs such as PowerShell. [2] WinRM can be used as a method of remotely interacting with Windows Management Instrumentation . [3]

 Mitigations 
 
 
 
 
 ID 
 Mitigation 
 Description 
 
 
 
 
 
 M1042 
 
 
 Disable or Remove Feature or Program 
 
 
 Disable the WinRM service. 

 
 
 
 
 M1030 
 
 
 Network Segmentation 
 
 
 If the service is necessary, lock down critical enclaves with separate WinRM infrastructure and follow WinRM best practices on use of host firewalls to restrict WinRM access to allow communication only to/from specific devices. [15] 

 
 
 
 
 M1026 
 
 
 Privileged Account Management 
 
 
 If the service is necessary, lock down critical enclaves with separate WinRM accounts and permissions.

 Behavioral Detection of WinRM-Based Remote Access 
 
 
 AN1313
