# superseded/

Superseded control-surface and methodology files, preserved verbatim with a
SHA-256 prefix on the filename.

## Why files are kept here rather than deleted

A constitution rewritten every session is not a constitution, and a file that
lived under a path two generations ago is often still linked from somewhere. So
the old path is never deleted — it is repointed at a one-line pointer naming the
current file, and the original is preserved here under its content hash.

## What belongs here

Only a file that was previously **authoritative** and has been replaced. If a
page was wrong but never canonical, correct it in place; do not archive it.

## Reading one

The SHA-256 prefix in the filename lets you prove a preserved copy is unmodified.
Compare it against the pointer file's recorded hash before treating the archived
content as evidence of what the system used to believe.
